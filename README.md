# Book and Author Management System - Frontend

Frontend εφαρμογή για τη διαχείριση βιβλίων και συγγραφέων.

## Τεχνολογίες
- React
- Axios
- React Router DOM

## Προαπαιτούμενα
- Node.js 18+
- npm

## Οδηγίες Εγκατάστασης

### 1. Εγκατάσταση dependencies
```cmd
npm install
```

### 2. Εκτέλεση
```cmd
npm start
```

Η εφαρμογή τρέχει στο `http://localhost:3000`

> **Σημείωση:** Το backend πρέπει να τρέχει στο `http://localhost:8080` πριν ξεκινήσεις το frontend.

## Σελίδες
| URL | Περιγραφή |
|-----|-----------|
| / | Λίστα βιβλίων |
| /authors | Λίστα συγγραφέων |
| /add-book | Προσθήκη βιβλίου |
| /add-author | Προσθήκη συγγραφέα |
| /edit-book/:isbn | Επεξεργασία βιβλίου |
| /edit-author/:id | Επεξεργασία συγγραφέα |
